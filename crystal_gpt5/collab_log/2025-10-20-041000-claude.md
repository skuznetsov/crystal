## Suggestions for Real Symbol Types

### Symbol hierarchy design:

```crystal
# symbol.cr
abstract class Symbol
  getter name : String
  getter node_id : ExprId  # Back-reference to AST

  def initialize(@name : String, @node_id : ExprId)
  end
end

# Macro symbol (Stage 1 focus)
class MacroSymbol < Symbol
  getter params : Array(String)?  # Macro parameter names
  getter body : ExprId             # MacroLiteral node

  def initialize(name : String, node_id : ExprId, @body : ExprId, @params : Array(String)? = nil)
    super(name, node_id)
  end
end

# Future: Method symbol (Stage 2+)
class MethodSymbol < Symbol
  getter params : Array(Param)
  getter return_type : TypeId?
  getter body : ExprId?

  # ...
end

# Future: Class symbol (Stage 2+)
class ClassSymbol < Symbol
  getter instance_vars : Hash(String, TypeId)
  getter methods : Array(MethodSymbol)
  getter superclass : ClassSymbol?

  # ...
end

# Future: Variable symbol (Stage 3+)
class VariableSymbol < Symbol
  getter declared_type : TypeId?
  getter inferred_type : TypeId?

  # ...
end
```

### Why this order:

**Stage 1**: Start with MacroSymbol only
- Simplest case
- No type info needed yet
- Just name + AST reference + body

**Stage 2**: Add MethodSymbol
- Methods have params (need to parse)
- May have return type annotations
- Body is optional (abstract methods)

**Stage 3**: Add ClassSymbol + VariableSymbol
- Classes need inheritance tracking
- Variables need type inference

## SymbolCollector Implementation Plan

### Minimal SymbolCollector (for Stage 1):

```crystal
# collectors/symbol_collector.cr
module CrystalGPT5
  module Compiler
    module Semantic
      class SymbolCollector
        def initialize(@program : Frontend::Program, @context : Context)
        end

        def collect
          @program.roots.each do |root_id|
            visit(root_id)
          end
        end

        private def visit(node_id : Frontend::ExprId)
          node = @program.arena[node_id]

          case node.kind
          when .macro_def?
            collect_macro(node_id, node)
          # TODO: when .class_def?, when .def? (Stage 2+)
          else
            # Skip other node types for now
          end
        end

        private def collect_macro(node_id : Frontend::ExprId, node : Frontend::ExpressionNode)
          name = String.new(node.macro_name.not_nil!)

          # Get macro body (should be MacroLiteral)
          body = node.left.not_nil!

          # Extract parameters if they exist (future work)
          params = nil  # TODO: parse macro parameters from AST

          symbol = MacroSymbol.new(name, node_id, body, params)

          begin
            @context.symbol_table.define(name, symbol)
          rescue e : SymbolRedefinitionError
            # TODO: emit diagnostic
            # For now: allow redefinition (Crystal allows macro reopening)
            @context.symbol_table.redefine(name, symbol)
          end
        end
      end
    end
  end
end
```

### SymbolCollector spec:

```crystal
# spec/semantic/symbol_collector_spec.cr
require "spec"

require "../../src/compiler/frontend/lexer"
require "../../src/compiler/frontend/parser"
require "../../src/compiler/semantic/symbol_table"
require "../../src/compiler/semantic/symbol"
require "../../src/compiler/semantic/context"
require "../../src/compiler/semantic/analyzer"
require "../../src/compiler/semantic/collectors/symbol_collector"

describe CrystalGPT5::Compiler::Semantic::SymbolCollector do
  it "collects macro definitions" do
    source = <<-CR
      macro foo
        body
      end
    CR

    lexer = CrystalGPT5::Compiler::Frontend::Lexer.new(source)
    parser = CrystalGPT5::Compiler::Frontend::Parser.new(lexer)
    program = parser.parse_program

    context = CrystalGPT5::Compiler::Semantic::Context.new
    collector = CrystalGPT5::Compiler::Semantic::SymbolCollector.new(program, context)
    collector.collect

    symbol = context.symbol_table.lookup("foo")
    symbol.should_not be_nil
    symbol.not_nil!.name.should eq("foo")
    symbol.should be_a(CrystalGPT5::Compiler::Semantic::MacroSymbol)
  end

  it "collects multiple macros" do
    source = <<-CR
      macro foo
      end
      macro bar
      end
    CR

    lexer = CrystalGPT5::Compiler::Frontend::Lexer.new(source)
    parser = CrystalGPT5::Compiler::Frontend::Parser.new(lexer)
    program = parser.parse_program

    context = CrystalGPT5::Compiler::Semantic::Context.new
    collector = CrystalGPT5::Compiler::Semantic::SymbolCollector.new(program, context)
    collector.collect

    context.symbol_table.lookup("foo").should_not be_nil
    context.symbol_table.lookup("bar").should_not be_nil
  end

  it "allows macro redefinition (Crystal semantics)" do
    source = <<-CR
      macro foo
        v1
      end
      macro foo
        v2
      end
    CR

    lexer = CrystalGPT5::Compiler::Frontend::Lexer.new(source)
    parser = CrystalGPT5::Compiler::Frontend::Parser.new(lexer)
    program = parser.parse_program

    context = CrystalGPT5::Compiler::Semantic::Context.new
    collector = CrystalGPT5::Compiler::Semantic::SymbolCollector.new(program, context)

    # Should not raise
    collector.collect

    # Latest definition should win
    symbol = context.symbol_table.lookup("foo")
    symbol.should_not be_nil
  end
end
```

## Potential Issues to Watch

### Issue 1: Macro parameters

**Challenge**: AST doesn't capture macro params yet
```crystal
macro foo(a, b)  # Where are a, b in AST?
  # ...
end
```

**Solution for Stage 1**:
- Set `params = nil` for now
- Add TODO comment
- Defer to Stage 2 when we parse method signatures

### Issue 2: Node type safety

**Challenge**: Casting `node.left` to body
```crystal
body = node.left.not_nil!  # What if this isn't MacroLiteral?
```

**Solution**:
- Add assertion/check
- Emit diagnostic if unexpected node type
- Parser should guarantee this, but defensive coding

### Issue 3: Redefinition strategy

**Challenge**: Crystal allows multiple macro definitions
```crystal
macro foo; end
macro foo; end  # Valid in Crystal (last wins)
```

**Solution**: Use `redefine` instead of `define` on duplicate
- Implemented ✓
- Matches Crystal semantics ✓
