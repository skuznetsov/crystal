## Implementation: Delimiter Depth Tracking

### Core Idea
Newlines should be **statement separators** outside delimiters, but **ignorable whitespace** inside delimiters.

```crystal
# Outside delimiters - newline ends statement
x = 1
y = 2

# Inside delimiters - newline is whitespace
foo(
  a,
  b
)
```

### Architecture Changes

**Added to Parser class** (parser.cr:16-19):


**Initialized in both constructors** (lines 30-32, 45-47):
```crystal

@bracket_depth = 0
@brace_depth = 0
```

### Helper Methods

**1. inside_delimiters?** (lines 488-492):
```crystal
private def inside_delimiters? : Bool
  @paren_depth > 0 || @bracket_depth > 0 || @brace_depth > 0
end
```

**2. skip_whitespace_and_optional_newlines** (lines 494-515):
```crystal
# Replaces skip_trivia in delimiter contexts
# Always skips: whitespace, comments
# Conditionally skips: newlines (only inside delimiters)
private def skip_whitespace_and_optional_newlines
  loop do
    case current_token.kind
    when Token::Kind::Whitespace, Token::Kind::Comment
      advance
    when Token::Kind::Newline
      if inside_delimiters?
        advance  # Skip newlines inside delimiters
      else
        break  # Newline is statement separator outside
      end
    else
      break
    end
  end
end
```

### Implementation Guide: case/when (P1)

**Step 1**: Add CaseNode schema to ast.cr
```crystal
struct CaseNode
  getter span : Span
  getter value : ExprId?  # nil for bare case
  getter branches : Array(CaseBranch)
  getter else_body : ExprId?
end

struct CaseBranch
  getter span : Span
  getter conditions : Array(ExprId)  # when A, B, C
  getter body : ExprId
end
```

**Step 2**: Add parse_case_expression to parser.cr
```crystal
private def parse_case_expression : ExprId
  start_span = current_token.span
  consume Token::Kind::Case

  # Optional case VALUE
  value = if current_token.kind == Token::Kind::Newline || current_token.kind == Token::Kind::When
    skip_whitespace_and_optional_newlines
    nil  # bare case
  else
    expr = parse_expression(0)
    skip_whitespace_and_optional_newlines
    expr
  end

  branches = [] of CaseBranch

  while current_token.kind == Token::Kind::When
    branches << parse_when_clause
    skip_whitespace_and_optional_newlines
  end

  else_body = if current_token.kind == Token::Kind::Else
    advance
    skip_whitespace_and_optional_newlines
    parse_statements_until(Token::Kind::End)
  else
    nil
  end

  consume Token::Kind::End

  @arena.add_typed(CaseNode.new(
    start_span.cover(previous_token.span),
    value,
    branches,
    else_body
  ))
end

private def parse_when_clause : CaseBranch
  start_span = current_token.span
  consume Token::Kind::When
  skip_whitespace_and_optional_newlines

  conditions = [] of ExprId
  loop do
    conditions << parse_expression(0)
    skip_whitespace_and_optional_newlines
    break unless current_token.kind == Token::Kind::Comma
    advance
    skip_whitespace_and_optional_newlines
  end

  # Expect newline or then
  if current_token.kind == Token::Kind::Newline
    skip_whitespace_and_optional_newlines
  elsif current_token.kind == Token::Kind::Then
    advance
    skip_whitespace_and_optional_newlines
  end

  body = parse_statements_until(Token::Kind::When, Token::Kind::Else, Token::Kind::End)

  CaseBranch.new(
    start_span.cover(@arena[body].span),
    conditions,
    body
  )
end
```

## Knowledge Core Entry

**Pattern**: Parser delimiter depth tracking for multi-line expressions

**Problem**: Newlines should be statement separators at top-level, but ignorable whitespace inside delimiters.

**Solution**: Track nesting depth for each delimiter type. Create conditional skip method that checks depth before skipping newlines.

**Evidence**: Phase 103 - lexer.cr errors reduced from 150+ to 57 (62%). test_multiline_*.cr all pass.

**Applicability**: Any parser needing context-sensitive newline handling. Common in Python-like significant-whitespace languages when adding delimiter expressions.

**Anti-patterns**:
- Changing skip_trivia globally → breaks top-level statement separation
- Not tracking depth → can't distinguish context
- Forgetting to decrement depth → all subsequent newlines become significant
