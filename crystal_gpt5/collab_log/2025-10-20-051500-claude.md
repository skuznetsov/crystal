## Issues Found and Fixed

### Issue 1: CLI String Interpolation Bug
**File**: src/compiler/cli.cr:95
**Problem**: Syntax error with char literal
```crystal
puts "#{'  ' * indent}#{label} #{name}"  # ❌ Crystal interprets '  ' as char
```

**Fix Applied**:
```crystal
puts "#{"  " * indent}#{label} #{name}"  # ✅ Use double quotes
```

**Root Cause**: Crystal's char literals use single quotes and must be exactly one character. For strings inside interpolation, use double quotes.
