# Block Scope Name Resolution

## Changes
- Updated `Semantic::NameResolver` to push a block/proc scope, register block parameters, and traverse their bodies (including default parameter expressions). Identifiers inside `do`/`{}` blocks now resolve to symbols and inherit outer variables correctly (`crystal_v2/src/compiler/semantic/resolvers/name_resolver.cr`).

- Manual JSON-RPC for `debug_tests/analyze_ast_errors.cr` confirms locals such as `content`/`lexer` resolve correctly inside iterator blocks.
