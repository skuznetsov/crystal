### ✅ handle_def Implementation (lines 74-107)
**Status**: Perfect - all requirements met

**Flow**:
1. Extract method name and parameters
2. Create method scope (with parent = current scope)
3. Create MethodSymbol with scope
4. Define in current table (global or class)
5. **Push method scope**
6. Define parameters as VariableSymbol in method scope
7. Visit method body expressions
8. **Pop scope**

**Code**:
```crystal
private def handle_def(node_id : Frontend::ExprId, node : ExpressionNode)
  name_slice = node.def_name
  return unless name_slice

  name = String.new(name_slice)
  params = node.def_params || [] of String

  # Create method scope with current table as parent
  method_scope = SymbolTable.new(current_table)
  method_symbol = MethodSymbol.new(name, node_id, params: params, scope: method_scope)

  # Define method in current scope
  table = current_table
  if table.local?(name)
    table.redefine(name, method_symbol)
  else
    table.define(name, method_symbol)
  end

  # Push scope and define parameters
  push_table(method_scope)

  params.each do |param_name|
    param_symbol = VariableSymbol.new(param_name, Frontend::ExprId.new(-1))
    if method_scope.local?(param_name)
      method_scope.redefine(param_name, param_symbol)
    else
      method_scope.define(param_name, param_symbol)
    end
  end

  # Visit body with method scope active
  (node.def_body || [] of Frontend::ExprId).each do |expr_id|
    visit(expr_id)
  end

  pop_table
end
```

**Analysis**:
- ✓ Method scope has parent (lexical scoping)
- ✓ Parameters defined as VariableSymbol
- ✓ Scope pushed before body traversal
- ✓ Scope popped after (prevents leaks)
- ✓ Handles redefinition (Crystal semantics)
- ✓ node_id = -1 for params (reasonable placeholder)

**Verdict**: No changes needed

3. Reuse scope if reopening, create new if first definition

**Code**:
```crystal
private def handle_class(node_id : Frontend::ExprId, node : ExpressionNode)
  name_slice = node.class_name
  return unless name_slice

  name = String.new(name_slice)
  super_name = node.class_super_name.try { |slice| String.new(slice) }

  table = current_table
  class_scope = SymbolTable.new(table)  # Default: create new scope

  # Check for class reopening
  existing = table.lookup_local(name)
  if existing.is_a?(ClassSymbol)
    class_scope = existing.scope  # ✓ Reuse existing scope!
  end

  # Create symbol (may override existing)
  class_symbol = ClassSymbol.new(name, node_id, scope: class_scope, superclass_name: super_name)

  if table.local?(name)
    table.redefine(name, class_symbol)
  else
    table.define(name, class_symbol)
  end

  # Visit body with class scope
  push_table(class_scope)
  (node.class_body || [] of ExprId).each do |expr_id|
    visit(expr_id)
  end
  pop_table
end
```

**Analysis**:
- ✓ Class scope has parent (can access outer scope)
- ✓ **Class reopening handled correctly** (reuses scope!)
- ✓ Superclass name captured (ready for inheritance)
- ✓ Scope pushed/popped correctly
- ✓ Methods defined in class go into class scope

**Verdict**: Excellent - class reopening is tricky and you nailed it!
