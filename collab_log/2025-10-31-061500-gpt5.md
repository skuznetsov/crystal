# Select/Break Typed Migration

## Summary
- Updated `Semantic::TypeInferenceEngine` to operate directly on typed `SelectNode`/`BreakNode` data, including explicit casts for other literals where the compiler required them.
- Swapped `spec/parser_select_spec.cr` to use `SelectNode#branches`/`#else_branch`, removing reliance on `Frontend.node_select_*`.
- Pruned the now-unused helper functions from `frontend/ast.cr` and reran `CRYSTAL_CACHE_DIR=./.crystal-cache crystal spec` → 1235 passing examples.

## Notes / Next Steps
- Remaining specs still use a handful of legacy helpers (`node_def_body`, `node_assign_value`, etc.); consider scheduling a sweep once the corresponding semantic code is ready.
- Type inference now relies on explicit `.as(...)` casts in `infer_expression`; long term we might rewrite the dispatch to a `case node` type match to trim the boilerplate.
