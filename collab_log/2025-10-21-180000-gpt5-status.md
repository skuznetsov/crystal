**Current (Phase 3):**

```crystal
# Numeric literals with types

# Assignments with type inference

# Arithmetic with promotion

# Conditionals with union types
result = if age > 18
  "adult"
else
  "minor"
end
# result : String | String → String

# Complex expressions
value = if score > 90.0
  100_i64
elsif score > 80.0
  50_i32  # Promotes to Int64 in union
else
  0_i32
end
# value : Int64 | Int64 | Int64 → Int64

# Multiple variables
a = 1
b = 2
c = a + b
d = c * 10
```

**Type inference traces through:**
- Assignments → tracked types
- Arithmetic → numeric promotion
- Comparisons → Bool type
- Control flow → union types
- Variable references → lookup tracked types

**Error reporting:**

### To Understand Architecture

1. **Type inference flow:**
   ```
   Parser → AST (with spans)
     ↓
   Type Inference Engine
     - infer_expression(expr_id) → Type
     - Track assignments: @assignments[name] = type
     - Promote numeric types: widest wins
     - Union types for branches: union_of([then, else])
     ↓
   TypeContext (stores expr_id → Type mapping)
   ```

2. **Key design patterns:**
   - Arena-based AST (memory efficient)
   - ExprId indices (not pointers)
   - Side tables (assignments, type context)
   - Production-ready fallbacks (safe defaults + upgrade paths)
