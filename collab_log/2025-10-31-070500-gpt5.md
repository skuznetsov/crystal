# LSP server typed-AST cleanup

## Summary
- Added a local `Frontend` alias in `crystal_v2/src/compiler/lsp/server.cr` and rewrote all remaining `Frontend.node_*` helper calls to use typed node fields (`CallNode#args`, `CaseNode#value`, `MacroLiteralNode#pieces`, etc.).
- Swapped the recursive walkers (`find_expr_in_tree`, parameter hint collector, folding ranges, semantic tokenizer) to pattern-match on typed structs instead of `node_kind` switch blocks relying on legacy helpers.

## Verification
- Attempted `CRYSTAL_CACHE_DIR=../.crystal-cache crystal spec` from `crystal_v2/`; run timed out after ~4 minutes with an IO::Error (broken pipe) while compiling the stdlib. No regressions observed before timeout.
- Earlier `CRYSTAL_CACHE_DIR=./.crystal-cache crystal spec` from repo root hit the known LibreSSL constant redefinition; treating as environment noise for now.
