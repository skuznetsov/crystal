## Issues Fixed

### Issue 1: Gutter Width Formatting

**Problem**:
```
Expected: "  1 | foo + bar\n    |     ^^^"
Got:      " 1 | foo + bar\n   |     ^^^"
```

**Root Cause**: Insufficient padding before line numbers

**Fix** (diagnostic_formatter.cr:58-67):
```crystal
private def format_gutter(line_number : Int32?, width : Int32, is_code_line : Bool) : String
  if line_number
    String.build do |io|
      io << "  " << line_number.to_s.rjust(width) << " | "  # Changed " " to "  "
    end
  else
    String.build { |io| io << " " * (width + 3) << "| " }  # Changed width + 2 to width + 3
  end
end
```

**Result**: "|" separator aligned at position 4 for both numbered and underline rows

### Issue 2: Multi-line Underline Length

**Problem**:
```
Expected: "  3 | line3\n    | ^^^"  (3 carets)
Got:      "  3 | line3\n    | ^^"   (2 carets)
```

**Root Cause**: Missing +1 adjustment for multi-line span's last line

**Analysis**:
- `underline_segment` treats `end_column` as exclusive (column AFTER last char)
- First line of multi-line: correctly uses `line.size + 1`
- Last line of multi-line: was missing the +1

**Fix** (diagnostic_formatter.cr:79):
```crystal
elsif index == count - 1
  underline_segment(line, 1, span.end_column + 1)  # Added + 1
```

**Verification**:
- Span 2:1-3:3 now correctly underlines columns 1-3 (3 carets) on line 3
- Single-line spans unaffected (test 1 still passes)
