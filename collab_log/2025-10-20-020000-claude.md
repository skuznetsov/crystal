## Implementation Summary

### Changes Made

#### 1. Extended MacroPiece struct (`ast.cr`)
```crystal
getter span : Span?  # NEW: Captures location of macro directive
```

Updated factory methods to accept optional span parameter:
- `text(value, span = nil)`
- `expression(expr, trim_left, trim_right, span = nil)`
- `control(kind, keyword, expr, trim_left, trim_right, iter_vars, iterable, span = nil)`

#### 2. Updated parser to capture spans (`parser.cr`)

**Control pieces** (`parse_macro_control_piece`):
```crystal
start_token = current_token  # Capture opening {
# ... parse control ...
end_token = previous_token   # Capture closing }
control_span = start_token.span.cover(end_token.span)
piece = MacroPiece.control(..., control_span)
```

**Expression pieces** (`parse_macro_expression_piece`):
```crystal
macro_span = start_token.span.cover(closing_span)
piece = MacroPiece.expression(macro_expr_id, left_trim, right_trim, macro_span)
```

#### 3. Added span verification specs

**Test 1**: Control piece spans
- Verifies `{% if condition %}` span captured
- Verifies `{% end %}` span captured
- Line and column assertions

**Test 2**: Expression piece spans
- Verifies `{{ value }}` span captured
- Line and column assertions
