## Technical Notes for Implementation

### Multi-line Parsing Strategy:

**Current code** (parser.cr, ~line 200):
```crystal
# Likely treats newline as statement terminator unconditionally
if current_token.kind == Token::Kind::Newline
  advance  # ends current expression
end
```

**Needed**:
```crystal
@paren_depth = 0
@bracket_depth = 0
@brace_depth = 0

def inside_delimiters?
  @paren_depth > 0 || @bracket_depth > 0 || @brace_depth > 0
end

def skip_optional_newlines
  while current_token.kind == Token::Kind::Newline
    advance if inside_delimiters?
  end
end

# In parse_arguments:
consume Token::Kind::LParen
@paren_depth += 1
skip_optional_newlines  # allow newline after (

args = [] of ExprId
loop do
  skip_optional_newlines
  args << parse_expression(0)
  skip_optional_newlines

  break unless current_token.kind == Token::Kind::Comma
  advance  # consume comma
end

@paren_depth -= 1
consume Token::Kind::RParen
```

### Case Expression Strategy:

**Add to parser.cr:**
```crystal
private def parse_case_expression : ExprId
  start_span = current_token.span
  consume Token::Kind::Case

  # Optional: case VALUE
  value = if current_token.kind == Token::Kind::Newline
    nil  # bare case
  else
    parse_expression(0)
  end

  skip_newlines

  branches = [] of CaseBranch
  else_body : ExprId? = nil

  while current_token.kind == Token::Kind::When
    branches << parse_when_clause
  end

  if current_token.kind == Token::Kind::Else
    advance
    skip_newlines
    else_body = parse_statements_until(Token::Kind::End)
  end

  consume Token::Kind::End

  @arena.add_typed(CaseNode.new(
    start_span.cover(previous_token.span),
    value,
    branches,
    else_body
  ))
end
```
