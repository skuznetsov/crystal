#### 4. Create span from start to end tokens (`parser.cr:269-274`)
```crystal
# Capture span if we have start and end tokens
span = if start_token && end_token
  start_token.span.cover(end_token.span)
elsif start_token
  start_token.span
end

pieces << MacroPiece.text(text, span)
```

## Edge Cases Handled

✅ **Trimmed text pieces**
- Text correctly trimmed (rstrip applied)
- Span still captures full original range
- Example: `"text before"` before `{{- expr }}` has span even when trimmed

✅ **Multi-line text segments**
- Span covers all lines from first token to last
- Example: Text spanning lines 2-5 has span with start_line=2, end_line=5

✅ **Empty buffers**
- `return if buffer.size == 0` prevents creating pieces for empty buffers
- No span creation for non-existent text

✅ **previous_token tracking**
- Parser's existing `@previous_token` mechanism provides accurate end position
- Works correctly across control/expression boundaries
